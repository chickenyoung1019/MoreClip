# セッション振り返り

このセッションで得られた知見をCLAUDE.mdに反映する。

## 手順

1. **会話を振り返る**
   - 新しく判明した事実（パス、コマンド、設定など）
   - 解決した問題とその解決方法
   - 確立したパターンや手順
   - 今後も使える知見

2. **CLAUDE.mdを確認**
   - 現在の内容を読む
   - 追加・更新すべき箇所を特定

3. **更新提案**
   - 追加すべき内容をリストアップ
   - 具体的な変更案を提示

4. **ユーザー確認後に更新**
   - 承認を得てから編集を実行

## 更新対象の例

- 新しいコマンドやパス
- 解決したハマりポイント
- 新しいサブエージェントやツール
- アーキテクチャの変更
- 設定値やキーの追加

## 注意

- 一時的な情報（デバッグ用のログなど）は追加しない
- 次のセッションでも有用な情報のみ追加
- 既存の内容と重複しないよう確認
- シンプルに保つ（冗長な説明は避ける）
